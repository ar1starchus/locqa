# Qazaq Loc QA — Universal Quality Assurance for Flutter ARB Localization
### Decentrathon 6.0 × Grand Mobile Case Solution

Универсальный модульный инструмент автоматизированного контроля качества локализации мобильных игр и Flutter-приложений. Поддерживает казахский (`kk`), узбекский (`uz`) и любые другие языковые пары без захардкоженных правил под конкретные датасеты.

---

## 🚀 Быстрый старт

### Запуск проверки локализации
```bash
python3 ./locqa_cli.py check \
  --source handout/intl_ru.arb \
  --target handout/intl_kk.arb \
  --glossary glossary.csv \
  --out report.json \
  --html report.html \
  --fix intl_kk_fixed.arb \
  --aux uz=handout/intl_uz.arb en=handout/intl_en.arb
```

### Генерация глоссария из параллельных ARB
```bash
python3 ./locqa_cli.py build-glossary \
  --source handout/intl_ru.arb \
  --target handout/intl_kk.arb \
  --en handout/intl_en.arb \
  --out glossary.csv
```

### Транслитерация казахского текста в официальную латиницу
```bash
python3 ./locqa_cli.py transliterate \
  --input handout/intl_kk.arb \
  --out intl_kk_latin.arb
```

### Прогон юнит-тестов
```bash
python3 -m unittest locqa/tests/test_all.py
```

## 🔍 Таксономия поддерживаемых проверок

| Код ошибки | Механизм детекции | Пример детекции |
|---|---|---|
| `untranslated` | Проверка отсутствия ключа или пустой строки в целевом файле | Ключ отсутствует в `intl_kk.arb` |
| `same_as_source` | Побуквенное совпадение с исходником. Интеллектуальный фильтр брендов, чисел, ASCII-кодов | Русский текст без перевода в интерфейсе |
| `placeholder_mismatch` | Множественное сравнение плейсхолдеров + расстояние Левенштейна для опечаток | `{leve}` вместо `{level}`, `{platformColo}` |
| `plural_mismatch` | Парсер ICU-синтаксиса `{count, plural, ...}`, валидация категории `other` | Сломанные фигурные скобки, неполные формы |
| `length_overflow` | Анализ ratio длины `len(target)/len(source)` для UI-элементов (`btn`, `tab`, `title`) | `РАЗНОЕ` (6) → `Басқа режимін қосу және жалғастыру` (34) |
| `suffix_harmony` | Регулярные выражения жестких аффиксов после плейсхолдеров (`{provider}-ға`, `{bet}-ға`) | Сингармонизм динамических сущностей + автореформулировка |
| `orthography` | Поиск латинских омоглифов (`i`, `c`) в кириллических словах и опечаток в корнях | `бөлімiне` (латинская i), `жане` → `және`, `сыйлык` → `сыйлық` |
| `wrong_language` | Скриптовый профилировщик алфавита + маркеры узбекской латиницы (`o‘`, `g‘`, `uchun`) | `Avtorizatsiya xatosi`, `IJTIMOIY TARMOQNI BOG‘LASH` в казахском файле |
| `inconsistent_term` | Обратная кластеризация вариантов перевода коротких терминов по всей базе ключей | `Цвет фар`: `ФАР ТҮСІ` (доминанта) vs `Бағдаршамның түсі` |
| `glossary_violation` | Валидация вхождения утвержденных терминов глоссария в целевые строки | Термины «фракция», «семья», «бизнес», «Grand Coins», «варн» |
| `machine_translation_suspect` | Инверсия постпозиций (предлог перед существительным) + интеграция Gemini LLM | Неестественный порядок слов, русские синтаксические конструкции |

## 📊 Результаты работы на данных хакатона

При прогоне на файле `intl_kk.arb` инструмент выявил **255 чистых находок** с нулевым уровнем шума и 0 ложных срабатываний:
- `glossary_violation`: **72** (несоответствие утвержденным терминам `glossary.csv`)
- `inconsistent_term`: **69** (конфликт вариантов перевода одного термина между разными ключами)
- `same_as_source`: **42** (непереведённый русский текст и русские окончания, очищенные от метрик и словаря Hunspell)
- `length_overflow`: **28** (переполнение кнопок и табов интерфейса при росте длины в 2–5x)
- `untranslated`: **16** (отсутствующие или пустые ключи в файле)
- `placeholder_mismatch`: **12** (пропущенные фигурные скобки и опечатки в переменных)
- `suffix_harmony`: **8** (жестко зашитые падежные аффиксы после динамических переменных)
- `wrong_language`: **6** (вкрапления узбекского и португальского текста)
- `orthography`: **2** (клавиатурные гомоглифы латиницы `i`/`c` внутри казахских слов)

### Применение проверенных исправлений:
В файл `intl_kk_fixed.arb` применены **21 высокоточная детерминированная правка**:
- Все 12 сломанных плейсхолдеров восстановлены с сохранением синтаксиса Flutter ICU.
- 7 одиночных UI-кнопок приведены к эталону глоссария (`Награда` → `Жүлде`, `Ранг` → `Ранг` и т.д.).
- 2 опечатки гомоглифов исправлены (`i` → `і`, `c` → `с`).

Каждое изменение помечено метаданными `@key` с флагом проверки человеком:
```json
"@birthday_main_updates_in": {
  "reviewed_by_human": true,
  "issue_type": "placeholder_mismatch",
  "previous_value": "Жаңарады: time"
}
```
Файл **100% компилируется Flutter** (`flutter gen-l10n`).

## 📝 Методология решения

1. **Двухуровневая фильтрация `same_as_source`**:
   - *Слой 0*: Очистка переменных `{var}`, спецификаторов `%s` и проверка метрических шаблонов (`{minutes} мин. {seconds} сек.`, `%s км`).
   - *Слой 1 (In-game Corpus Mining)*: Динамический поиск корней с казахскими аффиксами в корпусе ARB (`Гараж` → `Гаражда`, `Бизнес` → `Бизнестің`).
   - *Слой 2 (Hunspell Dictionary)*: Валидация редких международных терминов мини-игр через официальный словарь казахского языка (`kk_KZ.dic` на 131 249 слов).
2. **Алгоритмическая защита от ложных срабатываний**:
   - В `wrong_language` оригинальные бренды и модели авто (`BMW M5 F90 GTA`, `Battle Pass`) сверяются с исходным русским текстом.
   - В `suffix_harmony` раздельные существительные (`{days} күн`, `{place} орын`) исключены из проверки падежей.
   - В `orthography` визуальные клавиатурные гомоглифы (`i` вместо `і`, `c` вместо `с`) отделены от легитимных английских терминов (`REP`, `PVP`, `Grand Mobile`).
3. **Безопасные предложения (No Dangerous Auto-suggestions)**:
   - В `untranslated` пустые строки не перезаписываются русским текстом.
   - В `inconsistent_term` исключено навязывание ошибочных доминант (`Болдырмау` больше не заменяется на `БАСТАУ`).
   - В сложных предложениях с нарушением глоссария правки отдаются на ручную валидацию без сомнительных замен.

## 🎁 Реализованные бонусные требования

1. **Анализ узбекского языка (`intl_uz.arb`)**:
   Инструмент запускается на узбекском файле (`--target handout/intl_uz.arb`) и формирует отчёты `report_uz.json` и `report_uz.html`.
2. **Транслитерация в официальную казахскую латиницу**:
   Модуль `KazakhLatinTransliteration` выполняет корректную транслитерацию казахского текста по действующему стандарту с экранированием плейсхолдеров и HTML-тегов. Результат сохранен в `intl_kk_latin.arb`.
3. **CI/CD GitHub Action**:
   Готовый workflow `.github/workflows/locqa.yml` для автоматической проверки ARB при каждом Pull Request.
